# 야장하기 좋은 날

기존 Canvas의 `index.html`에 공공데이터 API를 연결하고, 제공해 주신 PC·모바일 이미지를 반영한 로컬 대시보드입니다. Node.js 24 LTS를 사용합니다. 혼잡도 카드는 표시하지 않습니다.

## 실행과 종료

새 PowerShell 창에서 실행해 주세요.

```powershell
cd C:\vibe
npm ci
node server.mjs
```

- 접속 주소: http://localhost:3000 (또는 http://127.0.0.1:3000)
- 종료: 실행한 터미널에서 `Ctrl+C`
- 이미 3000번 포트에서 실행 중이면 기존 화면을 사용하거나 기존 서버를 종료해 주세요.
- 다른 포트: `node server.mjs --port=3002`
- 설치된 Node.js가 현재 터미널의 PATH에 아직 반영되지 않았다면 아래 명령으로 실행해 주세요.

```powershell
& "$env:LOCALAPPDATA\Programs\nodejs\node.exe" C:\vibe\server.mjs
```

`preview.mjs`는 앞서 사용한 정적 화면 확인용 서버입니다. 실제 API 연결에는 `server.mjs`를 사용해 주세요. 서버는 이 PC에서만 접속할 수 있도록 127.0.0.1에 바인딩합니다.

## 인증키와 데이터

서버가 실행 파일 옆의 `.env`를 읽습니다. `API_KEY`와 기존 `DATA_GO_KR_API_KEY`를 모두 지원하며, 둘 다 있으면 `API_KEY`를 사용합니다. 인코딩된 인증키도 지원합니다. 원본 `.env`는 변경하지 않았습니다.

브라우저 → `/api/dashboard?region=seoul_mapo` → 공공데이터 API 순서로 요청합니다. 인증키와 원본 설정 파일은 브라우저로 보내지 않습니다. 서버는 HTML, API, 지정된 화면 CSS·JS와 Leaflet 파일만 제공합니다.

사용하는 공식 서비스:

- [기상청 단기예보·초단기실황](https://www.data.go.kr/data/15084084/openapi.do): `getVilageFcst`, `getUltraSrtNcst`
- [에어코리아 대기오염정보](https://www.data.go.kr/data/15073861/openapi.do): `getCtprvnRltmMesureDnsty`
- [행정안전부 일반음식점](https://www.data.go.kr/data/15154916/openapi.do): `general_restaurants/info`
- 행정안전부 휴게음식점: `rest_cafes/info`

음식점 API는 실제 명세에 따라 `cond[ROAD_NM_ADDR::LIKE]`와 `cond[SALS_STTS_CD::EQ]=01`을 사용합니다. PRD의 초기 요청변수 예시 `BLCV_CD`는 이 서비스의 검색 변수가 아니므로 사용하지 않습니다. 조회된 정상 영업 업소 중 서비스별 최대 6곳을 표시합니다. 도로명주소가 없는 업소는 현재 검색 결과에 포함되지 않을 수 있습니다. 음식점 목록의 ‘영업/정상’은 인허가 정보 기준입니다. 실시간 개점 여부와 영업시간은 이 API에서 제공하지 않습니다.

지도는 실제 업소 좌표(EPSG:5174)를 위경도로 변환하여 표시합니다. 음식점·카페 및 휴게음식점·주점 필터는 조회된 업소의 업태를 기준으로 합니다. 좌표가 없는 실제 업소는 네이버 지도 주소 검색으로 연결하며, 샘플 업소는 지도에 표시하지 않습니다. 지도와 목록은 지역의 전체 업소나 야외좌석 보유 업소 목록이 아닙니다. 지도 배경은 OpenStreetMap, 지도 UI는 Leaflet, 좌표 변환은 proj4를 사용합니다.

날씨는 서울 대표 격자(60,127), 마포구(59,127), 용산구(60,126), 종로구(60,127)를 사용합니다. 서울 전체의 날씨는 대표 격자 기준이며 전체 평균이 아닙니다. 대기는 구별 측정소 또는 서울 도시대기 유효 측정소 평균을 사용합니다. 관측 시각이 3시간보다 오래되거나 결측·점검 상태이면 샘플로 전환합니다.

화면은 30분마다 갱신합니다. 서버 캐시는 예보 30분, 실황·대기 15분, 음식점 3시간입니다. 공급자가 제공한 기준시각은 ‘데이터 출처와 기준 보기’에서 확인할 수 있으며 상단 조회 시각과 구별합니다. 날씨는 발표 후 15분, 실황은 45분의 제공 지연을 고려합니다. 16시 예보를 보존하기 위해 늦은 저녁에도 14시 발표본까지 사용합니다. 오늘 예보가 불완전하면 이전 발표본을 한 번 더 확인합니다.

## 점수 계산

공식 기관이 제공하는 지수가 아닌 자체 참고 점수입니다.

- 기온: 18~24°C이면 40점, 이 구간을 벗어날 때 1°C당 5점을 감점합니다(최저 0점).
- 강수: `40 × (1 - 강수확률/100)`점입니다. 강수형태가 비·눈 등인 시간은 기온+강수 점수를 최대 30점으로 제한합니다.
- 대기: PM10과 PM2.5 중 나쁜 등급을 기준으로 좋음 20점, 보통 14점, 나쁨 4점, 매우 나쁨 0점입니다. 등급 경계는 PM10 30/80/150, PM2.5 15/35/75㎍/㎥입니다.
- 시간별 지수: 기온+강수+대기 점수를 반올림합니다. 오늘의 지수는 16~22시 일곱 시간 점수 평균입니다. 최신 대기 관측값을 모든 시간대에 동일하게 적용하며, 미래 대기 예측값이 아닙니다.
- 골든타임: 연속 세 예보 시점(예: 18·19·20시)의 평균이 가장 높은 구간을 고릅니다. 평균 80점 이상일 때 추천하며, 동점이면 빠른 구간을 선택합니다. 막대를 누르면 해당 시간의 기온·강수확률·점수를 확인할 수 있습니다.
- 주간 베스트 데이: 미래 미세먼지 예측을 만들지 않고 저녁 기온+강수 평균을 100점으로 환산합니다. 오늘 지수와 산정 항목이 다름을 화면에 안내합니다. 동점이면 더 이른 날짜를 선택합니다. 16~22시 예보가 모두 있는 날짜만 비교하고, 나머지는 ‘예보 없음’으로 표시합니다.

## 샘플 전환과 검증

서버가 공급자별로 실패를 처리합니다. 일부만 실패하면 성공한 영역은 실제 데이터를 유지하고 실패한 영역에만 샘플 표시를 합니다. 기상·대기 샘플이 지수에 사용되면 지수도 ‘샘플 데이터 포함’으로 표시합니다. 인증키가 없으면 전체 샘플로 전환합니다. 서버 자체가 꺼졌을 때도 브라우저는 기존 HTML 내 샘플로 복구합니다. 샘플 기준시각은 실제 관측시각으로 바꾸지 않습니다.

원래 `data` 폴더는 없었으므로 기존 HTML의 `MOCK_DATABASE`를 변경 없이 `samples/dashboard.json`에 복사했습니다. HTML의 원본 샘플 객체도 보존했습니다.

```powershell
cd C:\vibe
node --test tests/dashboard.test.mjs
```

테스트는 임시 폴더의 가짜 인증키와 응답을 사용하며 원본 `.env`에 접근하거나 수정하지 않습니다. 인증 누락, 인코딩, 결측값, 시간 초과, API 오류, 부분 실패, 캐시 이후 인증 파일 제거, 내부 파일 접근 차단과 화면 자산 제공, 16~22시 평균, 골든타임, 업종 분류, 좌표 변환을 검사합니다.

원본 `.env`를 건드리지 않는 샘플 화면 실행 방법:

```powershell
node server.mjs --port=3001 --env-file=missing-test.env
```

`missing-test.env`가 없는 상태에서 http://localhost:3001 로 접속하시면 됩니다. 실제 검증에서는 `.env`를 복사하지 않은 별도 폴더에서도 실행해 샘플 표시를 확인했습니다.

화면 CSS·JS와 지도 라이브러리는 로컬에서 제공합니다. 실제 API 데이터와 지도 배경을 불러오려면 인터넷 연결이 필요합니다.
